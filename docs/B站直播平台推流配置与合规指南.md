# B站直播平台推流技术规范与合规配置指南

| 维度 | 关键结论与核心推荐 |
| :--- | :--- |
| **视频编码** | **H.264 / AVC**（绝对不要用 H.265/AV1） |
| **分辨率与帧率** | **推荐 1280x720 (720P) @ 30 FPS**（虚拟人弹幕直播性价比最高，挂机宝极省算力） |
| **码率控制** | **必须为 CBR（固定码率），推荐 2500 ~ 3000 Kbps** |
| **关键帧间隔** | **必须硬性设置为 2 秒**（绝对不能设为 0 / 自动） |
| **音频参数** | **AAC, 44.1 kHz, 128 Kbps, 立体声** |
| **合规与分区** | 必须在后台报备 **“AI 生成内容”**，分区推荐 **“虚拟主播 ➔ 虚拟综合”** |

---

## 一、 OBS 推流参数逐项对照表（针对 B站 直播）

在挂机宝上的 OBS 中，打开【设置】，依次对照以下标准配置进行填写：

### 1. 【输出】设置 (Output Settings)
* 先将顶部【输出模式】从“基本”切换为 **“高级”**：

| 配置项 | 推荐数值 | 原理解释与避坑要点 |
| :--- | :--- | :--- |
| **编码器** | **NVIDIA NVENC H.264**（若有显卡）<br>或 **x264**（纯 CPU 挂机宝） | 纯 CPU 机器千万不要尝试 AV1 或 H.265，x264 兼容性最好 |
| **码率控制** | **CBR**（固定码率） | **必须选 CBR**。若选 VBR（动态码率），网络稍有波动就会引发 B站服务器丢包断流 |
| **比特率 (码率)** | **2500 ~ 3000 Kbps** | B站普通用户上限一般为 6000 Kbps。设为 2500~3000 Kbps 既能保证 720P 清晰度，又能保证挂机宝小水管带宽不拥堵 |
| **关键帧间隔** | **2 秒** | **核心参数！** 默认的 0（自动）会导致观众端起播慢、转菊花、延迟累积到数十秒 |
| **CPU 使用预设** | **ultrafast**（x264 时）<br>或 **P1 / P3**（NVENC 时） | 极速模式，将 CPU 占用从 90% 骤降至 15% 左右，彻底解决推流卡顿 |
| **配置 (Profile)** | **high** 或 **main** | 标准 H.264 规格 |
| **最大 B 帧** | **2** | 维持默认即可 |

---

### 2. 【视频】设置 (Video Settings)
* 路径：`设置 ➔ 视频`

| 配置项 | 推荐数值 | 说明 |
| :--- | :--- | :--- |
| **基础 (画布) 分辨率** | `1280x720` | 与输出分辨率保持一致，避免二次缩放消耗计算资源 |
| **输出 (缩放) 分辨率** | `1280x720` | 720P 在手机端看画质完全足够，计算量仅为 1080P 的 40% |
| **缩小方法 (采样滤镜)**| 双线性 (Bilinear, 最快) | 最轻量，无抗锯齿重计算负担 |
| **常用 FPS 值** | **30** | **强烈推荐 30 帧**。对于虚拟人展示、弹幕浮层，30 帧完全流畅，不需要 60 帧白白浪费一倍算力 |

---

### 3. 【音频】设置 (Audio Settings)
* 路径：`设置 ➔ 音频`

| 配置项 | 推荐数值 | 说明 |
| :--- | :--- | :--- |
| **采样率** | **44.1 kHz** 或 48 kHz | 推荐 44.1 kHz，与网页端及 TTS 合成音频最匹配 |
| **声道** | 立体声 (Stereo) | 标准双声道 |

---

### 4. 【推流】设置 (Stream Settings)
* 路径：`设置 ➔ 推流`
* **服务**：选择 **“自定义...” (Custom...)**
* **服务器 (Server)**：填入 B站 后台获取的 **推流地址**（例如：`rtmp://live-push.bilivideo.com/live-bvc/`）
* **串流密钥 (Stream Key)**：填入 B站 后台获取的 **推流码**

## 二、 挂机宝 OBS 浏览器源配置（连接你的独立云服务器）

由于你的管理端与 Vue3 网页已经部署在已有独立服务器上，挂机宝只作为一个单纯的**“推流管道”**：

1. 在 OBS【来源】窗口，点击 `+` ➔ 新建 **“浏览器” (Browser)**：
   - **URL**：填入你的服务器大屏地址，例如 `http://你的云服务器公网IP:8000/live`
   - **宽度**：`1280`
   - **高度**：`720`
   - **自定义帧率**：勾选并设为 `30`
2. **关键属性防掉线设置**：
   - ❌ **取消勾选**【源不可见时关闭（Shutdown source when not visible）】
   - ❌ **取消勾选**【场景激活时刷新浏览器（Refresh browser when scene becomes active）】
   - 勾选【使用 OBS 控制音频】（若页面有 TTS 声音输出）
3. **关闭预览防卡顿**：
   - 在 OBS 中间画面上**右键 ➔ 取消勾选【启用预览】**，直接节省挂机宝 50% 算力！

## 三、 B站平台规则与 24 小时开播合规要求

在 B站 进行无人值守/AI 虚拟人直播，必须严格遵守以下平台治理规范，防止直播间被封禁：

### 1. 强制合规报备（“AI 生成合成内容”标识）
* **平台规则**：B站严厉打击未报备的 AI/虚拟人生成内容。
* **操作步骤**：
  1. 打开 B站【主播中心】➔【直播间设置】；
  2. 找到 **“AI 生成合成内容声明”** 选项并勾选开启；
  3. 直播间简介中补充一行小字声明：“*本直播间互动画面由 AI/程序实时渲染展示*”。

### 2. 直播分区合规选择
* **推荐合规分区**：
  - 首选：**`虚拟主播 ➔ 虚拟综合 / 虚拟日常`**
  - 次选：**`科技 ➔ 计算机·软件 / 人工智能`**
* **禁忌**：严禁挂在“单机游戏”、“影音馆”等不相关分区，会被巡查巡检判定为“挂错分区”强制切断推流。

### 3. 防“纯录播 / 死循环”算法巡检
* B站后台有针对无人直播的画面巡检算法：
  - 如果一个直播间数十分钟内画面完全定格、没有弹幕交互反馈、没有声音变化，会被算法直接打上“低质录播”标签，直接中断推流；
  - **对策**：保证观众发弹幕时，展示页能触发拟态弹幕上屏动效或虚拟形象动作/表情反馈。

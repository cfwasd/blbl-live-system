# 大肥鱼 AI 虚拟主播系统全功能使用与配置手册 (v0.4.0)

---

## 一、 系统架构总览

本系统专为 B站 (Bilibili) 及全网 24 小时无人/半无人二次元虚拟主播量身定制，包含两大部分：
1. **工业级综合管理控制台 (`/admin`)**：实时监控房间弹幕流水、一键切换 AI 人设、配置第三方 TTS 语音 API、管理直播间 BGM 与自动避让、OBS WebSocket 遥控推流、敏感词风控与房管紧急插播。
2. **极品二次元直播舞台 (`/live`)**：高帧率二次元大肥鱼娘动态立绘、自然眨眼与呼吸起伏、真实声波口型动态同步、黑胶唱片律动 BGM 播放器、深海浮动光粒特效、毛玻璃弹幕墙、SuperChat 醒目留言与大额礼物置顶。

## 二、 工业级管理端（/admin）八大核心功能

### 1. 📊 全景指挥看板 (Dashboard)
- **OBS 推流遥控**：通过 4455 端口 WebSocket 远程一键启动/停止 OBS 推流，免除远程桌面手动切屏风险。
- **核心数据看板**：实时显示已接收弹幕、敏感词过滤拦截数、活跃直播大屏连接数及 BGM 播放状态。
- **房管人工插播**：紧急情况下，房管可在此输入任意台词点击“播报”，主播即刻插话朗读并同步大屏嘴型。
- **开播前动效模拟器**：一键模拟普通弹幕、大额礼物、￥98 SuperChat 与违禁词，自检大屏动效。

### 2. 🧠 AI 大脑与 Prompt 人设
- **CPA (CLI-Proxy-API) 网关对接**：默认支持 `https://proxy.wangziheng.vip/v1`，搭载 `gemini-3.8-flash` 极速模型（TTFT 首字延迟 ~200ms）。
- **一键切换 4 套官方人设预设**：
  - 🐟 **大肥鱼 / Gemini娘**：元气呆萌、俏皮傲娇、偶尔小毒舌、爱吃白饭，每句 30 字以内高密度互动。
  - 🎀 **温柔治愈学妹**：声音甜美软萌，称呼观众为“学长/学姐”，积极给予情绪价值。
  - 😼 **高冷傲娇女王**：魔女御姐风，吐槽犀利，假装嫌弃实则宠粉。
  - 🎮 **激情热血游戏主播**：语速飞快、激情玩梗、气氛烘托组。
- **互动间隔防打架**：设置连续回复间隔（建议 4.0 - 6.0 秒），确保主播读完上一句有自然换气。
- **闲时主动暖场（防录播巡检）**：当超过设定秒数无弹幕互动，AI 主动自言自语卖萌碎碎念，彻底杜绝被平台判定为死寂画面。

### 3. 🗣️ TTS 语音专属 API 配置中心（重点升级）
支持 5 大发音驱动模式，并配备**在线真实发音试听**：
1. **🌐 浏览器原生高保真引擎 (Web Speech API)**：
   - 零延迟、零费用、免配置任何 API Key。
   - 内置声优：`Microsoft 晓晓` (经典甜美萝莉音)、`Microsoft 云希` (阳光元气正太音) 等。
2. **⚡ OpenAI 兼容标准接口 (/v1/audio/speech)**：
   - 适配目前市面上绝大多数开源/商业二次元模型（如 CosyVoice、GPT-SoVITS、Fish-Speech、各类中转站）。
   - 填写 API URL、Model (如 `tts-1` 或 `cosyvoice-v1`)、Voice ID、API Key。
3. **🤖 Google AI Studio 原生 (Gemini 3.1 Flash TTS Preview)**：
   - 填入 Google AI Studio API Key (`AIzaSy...`) 与 Voice ID (`Aoede` / `Kore`)，直连官方高表现力音频流。
4. **🐚 MiniMax 海螺语音 (拟真人声二次元顶级)**：
   - 支持呼吸感、叹气与丰富情感起伏。
5. **🛠️ 自定义音频合成接口**：
   - 适配本地自建 FastAPI TTS 服务，直接返回二进制音频流。

> **在线试听**：点击【在线试听当前声音】，系统会根据所选引擎真实发起测试请求并播放音频，若配置有误将弹出详细报错提示。

### 4. 🎵 直播间 BGM 与 AI 智能避让 (Audio Ducking)
- **解决直播冷场**：内置无版权二次元元气日系与 Lo-Fi 伴奏曲目。
- **自动避让 (Ducking)**：
  - 平时正常伴奏音量：推荐 35% ~ 40%。
  - 主播发音避让音量：当检测到 AI 或房管开始说话，音乐音量毫秒级平滑降至 8%，人声清晰突出；话音结束后平滑淡入恢复。
- **打赏专属音效 (SFX)**：支持测试礼物感谢音效与 SuperChat 专属登场音效。

### 5. 🎭 舞台视觉与 Live2D 形象
- **场景主题切换**：
  - 🌊 **赛博深海幻想**：大肥鱼专属深邃光影、水波流光与生物荧光粒子。
  - 🎀 **温馨二次元房间**：梦幻少女电竞房氛围。
  - 🔲 **OBS 纯净透明通道**：推流专用，完全无底色透明，可随意叠加在游戏/桌面窗口之上。
- **主播形象选择**：
  - **极品大肥鱼娘 (Native Anime Mascot)**：内置高保真矢量萌系形象，配备双马尾鱼鳍飘动、自然眨眼、呼吸起伏与真实声波口型张合，加载 0 延迟，彻底告别白屏与 emoji。
  - **Live2D 模型 (日和 Hiyori / 静久 Shizuku / 自定义 .model3.json)**：支持外部 Live2D 模型加载。
- **形象控制**：支持实时滑块调节角色缩放大小 (Scale) 与屏幕水平停靠位置 (X 轴)。

### 6. 📡 B站长连接与房间号管理
- 输入任意长号或短号，系统后台自动调用 Bilibili 官方接口换算真实 Room ID。
- 采用原生 WebSocket 长连接实时监听 `DANMU_MSG`、`SEND_GIFT`、`SUPER_CHAT_MESSAGE`、`GUARD_BUY`。
- 可选填 `SESSDATA` Cookie，提升观众粉丝团勋章解析度。

### 7. 🛡️ 弹幕风控与敏感词库
- **Aho-Corasick 多模式自动机算法**：百万级违禁词纳秒级过滤。
- **风控参数**：单用户发言限频冷却、单条弹幕最大字数限制。
- **敏感词库管理**：在线实时添加/移除违禁词，一键持久化保存到 `configs/banned_words.txt`。

### 8. 📋 实时互动与系统日志
- 瀑布流展示观众弹幕、AI 思考生成的回复台词、礼物投喂记录与 SC 留存。

## 三、 直播舞台（/live）画面展示与快捷键

- **访问地址**：`http://localhost:8000/live`
- **快捷键**：
  - 按键盘 `T` 键：一键在“深海场景”与“OBS纯透明通道”之间切换。
  - 按键盘 `M` 键：一键播放 / 暂停 BGM 伴奏。
- **OBS 推流添加方式**：
  1. 打开 OBS Studio，在“来源”面板点击 `+`，选择 **浏览器** (Browser Source)。
  2. URL 填入：`http://localhost:8000/live`。
  3. 宽度设为 `1920`，高度设为 `1080`。
  4. 勾选 **通过 OBS 控制音频**。
  5. 若希望将大肥鱼主播和弹幕框悬浮在已有游戏画面上方，请在管理端将舞台主题选为 **OBS 纯净透明通道**（或按 `T` 键切换）。

## 1. 架构升级概览 (v0.2 关键演进)

针对初稿 v0.1 进行了三项关键生产力与视觉体验升级：
1. **管理端轻量化与低心智设计**：
   - 摒弃厚重的全栈构建流程，管理后台采用 **FastAPI 静态托管 + Vue 3 (CDN) + Tailwind CSS**，开箱即用，免打包构建，天然同源免 CORS。
2. **直播展示页工业级视觉重构**：
   - 采用 **Vue 3 + TypeScript + Vite + Pixi.js (v7) + `pixi-live2d-display`** 构建高颜值沉浸式大屏。
   - 具备**全透明通道**、**Live2D 虚拟人物**（呼吸/视线跟随/表情动作/Web Audio 实时口型同步 LipSync）、**拟态毛玻璃弹幕流**与 **SC 置顶卡片**。
3. **全栈 Docker 容器化体系**：
   - 提供 **Multi-Stage 多阶段构建 Dockerfile**（Node 编译前端 ➔ Python 生产镜像打包），支持一条命令一键交付与跨平台部署；
   - 配置文件与 Live2D 模型资产通过 Volume 外部挂载，保障数据持久化与随时更换模型。

## 3. 前端工程化与 Live2D 架构

### 3.1 目录组织 (Monorepo 友好结构)
```text
.
├── admin/                    # Python 后端源码
│   ├── core/                 # blivedm 接入、管线与广播中心
│   ├── routers/              # SSE 端点与 REST API
│   ├── static/               # 托管编译后的前端静态资源
│   │   ├── admin/            # 管理后台单文件 SPA (index.html)
│   │   └── live/             # 由 frontend 打包生成的 dist
│   └── main.py               # FastAPI 入口
├── frontend/                 # 直播大屏 Vue 3 工程
│   ├── src/
│   │   ├── assets/           # 样式与公共图标
│   │   ├── components/       # DanmuList, SuperChat, Live2DStage 等组件
│   │   ├── composables/      # useSSE, useLipSync, useLive2D 逻辑复用
│   │   ├── App.vue
│   │   └── main.ts
│   ├── index.html            # 引入 live2dcubismcore.min.js
│   ├── package.json
│   └── vite.config.ts
├── models/                   # 存放各套 Live2D 模型资源
├── configs/                  # 运行时动态配置文件
├── Dockerfile                # 多阶段统一构建镜像
├── docker-compose.yml        # 容器编排配置
└── README.md
```

### 3.2 Live2D 口型与动作驱动
前端在 `useLive2D.ts` 中封装 `pixi-live2d-display`：
* **模型自适应缩放**：根据 OBS 画布分辨率（1080P 或 720P）自适应对齐右下角或居中位置。
* **口型同步（LipSync）**：
  - 当接收到 `tts_audio` 事件播放音频时，利用 Web Audio API 创建 `AnalyserNode`，实时提取中低频振幅，动态映射至 Live2D 模型的 `ParamMouthOpenY` 参数。
* **情绪与动作（Motion & Expression）**：
  - 收到高等级礼物或 SC 时，自动触发预设 Motion（如挥手、鞠躬）与 Expression（如开心笑脸）。

## 4. 交付与部署流程 (Docker 驱动)

### 4.1 镜像构建命令
```bash
docker build -t virtual-ai-live:v0.2 .
```

### 4.2 容器一键启动
```bash
docker run -d \
  --name ai-live \
  -p 8000:8000 \
  -v $(pwd)/configs:/app/configs \
  -v $(pwd)/models:/app/models \
  -e ROOM_ID=21452505 \
  --restart unless-stopped \
  virtual-ai-live:v0.2
```
